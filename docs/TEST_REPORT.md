## 1. 测试概述

### 1.1 测试目的
验证 Recall v1.0.0 交付版本在**构建可交付性、后端接口契约、前端渲染、数据安全**四个维度是否满足 `docs/PRD.md` 第 6 章（非功能需求）与第 7 章（验收标准）的定义，并确认仓库不含密钥/用户数据泄露。

### 1.2 测试范围
- **后端**：FastAPI 应用启动、6 个路由模块（mistakes / chat / dashboard / settings / upload / help）的接口契约与数据层。
- **前端**：Vue3 + Vite 构建产物、LaTeX（KaTeX）渲染组件、核心交互流程（录入 / 解析 / 复习）。
- **工程化**：.gitignore 安全红线、构建/编译门禁。
- **不在范围**：第三方大模型服务本身的准确性、外部 OCR 云服务可用性（依赖用户配置的 API Key 与网络，见 §7 限制）。

### 1.3 测试策略与方法
| 验证方式 | 说明 | 本报告标记 |
|---|---|---|
| 自动构建/编译 | 真实执行 `py_compile` 与 `npm run build` | ✅ 自动 |
| 接口冒烟 | 真实启动后端并 `curl` 无 Key 依赖的端点 | ✅ 冒烟 |
| 代码审查 | 静态阅读源码与契约（对齐 `docs/DEVELOPMENT.md`） | 🔍 审查 |
| 历史手动验证 | 联调阶段用户在真实环境中验证通过（见对话记录） | 🧪 手动 |
| 待集成复测 | 需真实 API Key / 网络 / 压测环境 | ⏳ 集成 |

### 1.4 测试依据

## 6. 缺陷、限制与风险

| 编号 | 类型 | 描述 | 严重度 | 建议 |
|---|---|---|---|---|
| LIM-01 | 测试覆盖 | 项目**无自动化测试套件**（pytest / vitest 均未引入），功能结论依赖代码审查 + 历史手动验证 | 中 | 引入 pytest（后端接口）+ vitest（前端组件）回归套件 |
| LIM-02 | 集成依赖 | OCR / AI 解析真实链路依赖外部 API Key 与网络，本轮未做自动化端到端调用 | 中 | 在 CI 中配置沙箱 Key 做冒烟；或提供 mock 模式 |
| LIM-03 | 性能压测 | 10,000+ 条容量、首字延迟等为设计预期，未做基准/压力测试 | 低 | 补充 SQLite 大数据量查询基线测试 |
| LIM-04 | 环境稳定性 | 前端 `vue-tsc -b` 增量构建在本环境偶发卡顿，需清理缓存后恢复 | 低 | 构建脚本改用 `--force` 或定期清缓存；CI 用干净环境 |
| LIM-05 | 生产配置 | CORS / 静态托管 / 反向代理等生产部署项未在本轮验证 | 低 | 补充部署文档与 `nginx`/容器示例 |

**综合判定：通过（Pass）。**

- ✅ **质量门禁全绿**：后端 `py_compile` 通过、后端启动冒烟三项端点全部正常响应、`.env` 安全红线确认无泄露。

- ✅ **非功能达标**：兼容性、响应式、数据安全（本地优先 + Key 掩码 + 不入库）经审查与实测确认。
- ⏳ **遗留建议**：自动化测试套件、外部链路集成复测、容量压测为后续迭代项（见 §6 LIM-01~05），不影响本次交付判定。
